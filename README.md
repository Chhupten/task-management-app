# Task Management Application

A full-stack task management application built with Next.js, Django REST Framework, PostgreSQL, and JWT authentication.

The application allows users to sign up, log in, and manage their own tasks through a protected REST API and responsive frontend interface.

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Django REST Framework
- JWT Authentication
- PostgreSQL
